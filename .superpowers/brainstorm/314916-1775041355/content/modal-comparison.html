A

DialogShell Genérica + Fix Tipos (Recomendado)

Extrair OrdemDialogShell → DialogShell em components/ui. Refatorar ModalClientes e ModalVeiculos para usar. Corrigir tipos com z.infer. Alinhar labels com CLAUDE.md.

B

Fix Inline (Sem Shell Compartilhada)

Corrigir diretamente nos modais: ajustar padding, ícone, labels, tipos. Cada modal mantém sua estrutura independente com primitivos Dialog/ScrollArea.

C

Reescrita Completa + Drop React Hook Form

Migrar para o padrão da seção Ordens: manual state + validate() + FieldErrors. Máxima consistência, mas maior risco e escopo.
