Como deve ser cada item de alerta?

Cada produto em alerta — como você quer que a informação apareça?

A

Card compacto em linha

Ícone + nome + código + quantidade atual vs mínimo + botão "Repor" — tudo numa linha horizontal. Lista densa, boa para ver muitos itens de uma vez.

B

Card com barra de progresso visual

Linha horizontal com ícone, nome e quantidade, mais uma barra de progresso colorida mostrando o quão crítico está o nível. Mais visual e expressivo.

C

Card expandido com mais contexto

Card um pouco maior com ícone, nome, código, quantidade, mínimo configurado, e talvez uma sugestão de quanto repor. Mais informação por item.
